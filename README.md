## Thư mục dự án
| Thư mục | Nội dung |
| :--- | :--- |
| `data/` | chứa các file dữ liệu Execl quản lý học phí |
| `docs/` | chứa tài liệu hướng dẫn và báo cáo |
| `logs/` | lưu lại nhật ký hệ thống |
